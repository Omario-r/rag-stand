# RAG-stand — локальный стенд

Рабочая среда проекта RAG-lab. **Документация и обоснования — в волте:**
`~/Development/Home/RAG/research/reference/local-stand.md`. Здесь только как пользоваться.

Эта папка намеренно **вне git-репозитория волта**: тут модели на 8 ГБ,
ключи и будущий корпус договоров — ничего из этого не должно попасть в коммит.

## Команды

```bash
./start-stand.sh    # поднять всё: Qdrant + эмбеддер + реранкер + модель
./check-stand.sh    # проверить: доступность, безопасность, качество векторов
./stop-stand.sh     # остановить (данные в storage/ остаются)
```

Дашборд Qdrant: http://127.0.0.1:6333/dashboard — при входе спросит API-ключ,
он в `.env`.

> [!warning] Первый запуск генеративной модели
> `start-stand.sh` не скачивает модель, а ждёт её и падает по таймауту:
> T-lite весит 6,26 ГБ, а канал медленный. Скачивание делается отдельно
> и заранее — `./run-llm.sh`, один раз. Дальше берётся из кэша `models/`.

## Что где

| Путь | Что |
|---|---|
| `.env` | Адреса и ключи. **Не коммитить**, права 600 |
| `bin/qdrant` | Нативный бинарник Qdrant 1.19.0 (без Docker) |
| `storage/` | Данные Qdrant — коллекции, пойнты |
| `data/` | SQL-база второго контура — `contracts.sqlite`. **Не в `cache/`**: `pending` прогоном не восстанавливается |
| `snapshots/` | Снапшоты коллекций |
| `models/` | Кэш GGUF-моделей (8 ГБ: эмбеддер 624 МБ, e5 партнёра 575 МБ, реранкер 608 МБ, T-lite 6,3 ГБ) |
| `static/` | Веб-интерфейс Qdrant |
| `logs/` | Логи четырёх сервисов |
| `run-*.sh` | Запуск отдельного сервиса; вся конфигурация — там, с комментариями |

## Порты

| Порт | Сервис |
|---|---|
| 6333 | Qdrant REST + дашборд |
| 6334 | Qdrant gRPC (для быстрой загрузки) |
| 8080 | Эмбеддер — Qwen3-Embedding-0.6B, размерность 1024 |
| 8081 | Реранкер — bge-reranker-v2-m3 |
| 8084 | Генеративная модель — T-lite-it-2.1 Q6_K, контекст 8192 |

Все пять слушают **только 127.0.0.1** и требуют API-ключ.

Эмбеддер партнёра (`multilingual-e5-large`) поднимается отдельно —
`./run-embedder-e5.sh`, только для сравнительных замеров, в `start-stand.sh`
не входит.
