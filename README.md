# RAG-stand — локальный стенд

Рабочая среда проекта RAG-lab. **Документация и обоснования — в волте:**
`~/Development/Home/RAG/08-local-stand.md`. Здесь только как пользоваться.

Эта папка намеренно **вне git-репозитория волта**: тут модели на 1,2 ГБ,
ключи и будущий корпус договоров — ничего из этого не должно попасть в коммит.

## Команды

```bash
./start-stand.sh    # поднять всё: Qdrant + эмбеддер + реранкер
./check-stand.sh    # проверить: доступность, безопасность, качество векторов
./stop-stand.sh     # остановить (данные в storage/ остаются)
```

Дашборд Qdrant: http://127.0.0.1:6333/dashboard — при входе спросит API-ключ,
он в `.env`.

## Что где

| Путь | Что |
|---|---|
| `.env` | Адреса и ключи. **Не коммитить**, права 600 |
| `bin/qdrant` | Нативный бинарник Qdrant 1.19.0 (без Docker) |
| `storage/` | Данные Qdrant — коллекции, пойнты |
| `snapshots/` | Снапшоты коллекций |
| `models/` | Кэш GGUF-моделей (1,2 ГБ) |
| `static/` | Веб-интерфейс Qdrant |
| `logs/` | Логи трёх сервисов |
| `run-*.sh` | Запуск отдельного сервиса; вся конфигурация — там, с комментариями |

## Порты

| Порт | Сервис |
|---|---|
| 6333 | Qdrant REST + дашборд |
| 6334 | Qdrant gRPC (для быстрой загрузки) |
| 8080 | Эмбеддер — Qwen3-Embedding-0.6B, размерность 1024 |
| 8081 | Реранкер — bge-reranker-v2-m3 |

Все четыре слушают **только 127.0.0.1** и требуют API-ключ.
